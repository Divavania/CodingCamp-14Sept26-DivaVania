## Expense & Budget Visualizer

Expense & Budget Visualizer is a simple web application for tracking daily expenses. Users can add transactions, view total spending, organize expenses by category, and visualize spending through a pie chart.

## Features

- Add expense transactions
- Enter item name, amount, and category
- Input validation
- Display total spending
- Display a scrollable transaction list
- Delete transactions with confirmation
- Display expenses using a pie chart
- Add custom categories
- Sort transactions by:
  - Default order
  - Amount: Low to High
  - Amount: High to Low
  - Category: A to Z
- Light Mode and Dark Mode
- Persistent data using Local Storage
- Responsive layout for desktop and mobile devices
- Empty state when there are no transactions

## Technologies

- HTML5
- CSS3
- JavaScript
- Chart.js
- Local Storage
